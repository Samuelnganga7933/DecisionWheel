# DecisionWheel

A small iOS app for turning indecision into a spin.

Add a few options, give the wheel a flick, and let chance make the call. The project is intentionally simple: a focused interaction, a little motion, and a satisfying result.

## Stack

`Swift` `SwiftUI`

## Highlights

- Editable wheel options
- Custom segment shapes
- Confetti result state
- Swift 6 compatibility work
- Native iOS project structure

## Status

An iOS prototype. Building and running it requires Xcode on macOS.
